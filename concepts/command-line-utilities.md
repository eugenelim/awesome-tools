# Command-line utilities

Small terminal tools for searching code, finding files, processing JSON and viewing directory trees.

| Tool | Purpose | Licence | Homebrew |
| --- | --- | --- | --- |
| [ripgrep (rg)](../tools/ripgrep.md) | Recursive regex search that respects `.gitignore` | Unlicense OR MIT | `ripgrep` |
| [fd](../tools/fd.md) | Faster, simpler `find` | Apache-2.0 OR MIT | `fd` |
| [jq](../tools/jq.md) | JSON processor | MIT | `jq` |
| [tree](../tools/tree.md) | Directory tree view | GPL-2.0-or-later | `tree` |

Install all four:

```sh
brew install ripgrep fd jq tree
```
