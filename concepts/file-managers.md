# File managers

Applications for browsing and organising files across local, network and cloud storage.

## macOS (Finder alternatives)

| | [Swift Salamander](../tools/swift-salamander.md) | [Rascal](../tools/rascal.md) |
| --- | --- | --- |
| Platform | macOS 13+, Apple silicon only | macOS 13+, Apple silicon and Intel |
| Licence | | MIT |
| Pricing | Free; Pro $15 one-time (Early Access) | Free, no paid tier |
| Panes | 1–2 free; 3–4 in Pro | Dual panes, tabs |
| Remote storage | 38 cloud providers, SFTP, SMB, WebDAV (Pro) | |
| Keyboard | Command palette | Command palette, vim keys |
| Disk usage | Disk analyser (Pro) | Disk treemap |
| Telemetry | None | None |
| Homebrew | `--cask c0desurfer/tap/swift-salamander` | `--cask chang-07/tap/rascal` |

Both install from their developers' own Homebrew taps rather than homebrew/cask.

| --- | --- | --- | --- |

| Remote | | FTP/SFTP | FTP (SSL/TLS), network shares |

**Maintainer's view:** OneCommander has the best aesthetic of the three.

At work, note that OneCommander needs a paid Pro licence for professional or commercial use. FreeCommander and Multi Commander are listed as freeware in winget.
