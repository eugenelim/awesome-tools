# Agentic development environments

Applications for running and supervising several AI coding agents at once. They combine terminals, agent sessions and git worktrees. Both tools below describe themselves as an ADE.

| | [VelaTerm](../tools/velaterm.md) | [Orca](../tools/orca.md) |
| --- | --- | --- |
| Licence | MIT | MIT |
| Organising unit | Session tree | Worktree per task |
| Multi-agent | Plan / Execute mode; cross-session messaging | Same prompt to multiple agents, then compare |
| Review | Conversation and terminal views | Diff annotations, CI, PRs, GitHub/Linear |
| Desktop | macOS, Windows, Linux | macOS, Windows, Linux |
| Mobile | iOS, Android | iOS, Android |

See also [terminal emulators](./terminal-emulators.md) and [AI coding agents](./ai-coding-agents.md).
