# Ontology editors

Tools for building and maintaining OWL ontologies, SKOS thesauri and other RDF vocabularies.

| | [Protégé](../tools/protege.md) | [WebProtégé (self-hosted)](../tools/webprotege.md) | [VocBench](../tools/vocbench.md) |
| --- | --- | --- | --- |
| Delivery | Desktop app (Java) and hosted WebProtégé | Self-hosted web app (Docker Compose) | Self-hosted web app (Java 17+ or Docker) |
| Models | OWL 2, RDF | OWL 2 | OWL, SKOS/SKOS-XL, OntoLex-lemon, RDF |
| Collaboration | WebProtégé: permissions, discussions, revision history | Permissions, discussions, revision history; Keycloak sign-in | Multi-user, multilingual |
| Reasoning | HermiT, Pellet (desktop) | | |
| Licence | BSD-2-Clause-Views | BSD-2-Clause (deployment; some services unstated) | Open source |

To define a schema in YAML and generate OWL, SHACL, JSON Schema and code from it, see [LinkML](../tools/linkml.md) in [Data modelling](./data-modelling.md).
