# Personal AI agents

AI agents that carry out everyday tasks and longer-running goals on a person's behalf, usually through chat apps.

| | [Muse](../tools/muse.md) | [Hermes Agent](../tools/hermes.md) |
| --- | --- | --- |
| Maker | Meta | Nous Research |
| Hosting | Hosted; per-user cloud VM | Self-hosted: laptop, VPS, Docker, SSH, serverless |
| Licence | | MIT |
| Models | | Any provider |
| Chat | Muse app (mobile, Mac), WhatsApp | Terminal UI, Telegram, Discord, Slack, WhatsApp, Signal, email |
| Safeguards | Approval before actions, audit trail, hidden credentials, one-time cards | You choose the backend and tool permissions |
| Homebrew | Cask disabled | `hermes-agent`, `--cask hermes-desktop` |

For agents that write code, see [AI coding agents](./ai-coding-agents.md).
